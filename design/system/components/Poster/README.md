The typographic poster: the cover a short shows until it has art cleared for use. Title in poster capitals, director and year, a film-perforation strip on the left.

- Provide: `title`, `director`, `year`, and a `tone`: `sala` (default), `tungsteno`, `plata`; `telon` only inside a sponsored collection.
- Vary tones along a rail so neighbours differ; never put two `tungsteno` posters next to each other.
- Always `ratio-poster` (2:3). The label read by screen readers is the title and the director.
