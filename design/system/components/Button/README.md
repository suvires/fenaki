The one way to trigger an action. `primary` (tungsteno) is the main action of a view and appears once; `secondary` for the rest; `ghost` for low-weight links that look like actions.

- Provide: `children` (label from the locale files), optional `icon` (`play`, `plus`, `search`, `arrow`), `href` to render a link.
- `size="lg"` in heroes and on the player; `md` everywhere else.
- Labels say what happens: «Ver ahora», not «Play» or «Clic aquí».
- Never put two primary buttons side by side.
